Video Subtitle Remover - Portable Full Package
================================================

1. Extract the whole folder to drive D: (recommended).
2. Run SubtitleRemover.exe.
3. Open Settings > Advanced Settings > Application data folder.
4. Select a folder on D:, for example D:\VideoSubtitleRemoverData.
5. Restart the app.

The selected folder contains config, caches, OCR checkpoints, encrypted API
secrets, temporary files, and default output videos. Keep the complete _internal
folder next to SubtitleRemover.exe. No Python installation is required.

The API key file is encrypted with Windows DPAPI and can only be decrypted by
the same Windows user account.
